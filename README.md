# Supermarket_Sales

# 🛒 Projeto: Análise de Vendas de Supermercado

Este projeto utiliza dados reais de vendas de supermercado para realizar uma análise exploratória e identificar padrões de comportamento, categorias mais lucrativas, ticket médio e tendências temporais.

## 🎯 Objetivo

Aplicar técnicas de análise de dados com Python para extrair insights estratégicos a partir de um dataset público de vendas.

---

## 🧰 Ferramentas Utilizadas

- Python 3.10+
- Pandas
- Seaborn
- Matplotlib
- Google Colab ou Jupyter Notebook

---

## 📊 Análises Realizadas

- Total de vendas por cidade
- Produtos mais vendidos e lucrativos
- Evolução das vendas ao longo do tempo
- Ticket médio
- Preferência por forma de pagamento
- Distribuição por tipo de cliente e gênero

---

## 📌 Resultados Principais

- A cidade de **Naypyitaw** apresentou o maior volume de vendas.
- A categoria de produtos **Food and beverages** foi a mais lucrativa.
- As vendas Apesar da variação, não há uma tendência clara de crescimento ou queda ao longo do trimestre — o comportamento parece estável, porém volátil.
- O **ticket médio** foi de aproximadamente R$322.97.
- A forma de pagamento preferida pelos clientes foi **E-wallet**.
